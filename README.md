# Лабораторна робота №4: Файловий менеджер

## Тема
Робота з файловою системою в React Native з використанням бібліотеки `expo-file-system`.

## Опис проєкту
Мобільний застосунок, який забезпечує базові операції з керування файлами та папками у внутрішній пам'яті додатка. Проєкт дозволяє користувачу навігувати директоріями, створювати нові об'єкти, редагувати текстові файли та контролювати використання дискового простору.

## Реалізований функціонал
- **Навігація:** перехід між вкладеними директоріями, відображення поточного шляху та можливість повернення до попередньої папки.
- **Маніпуляція файлами:** створення нових папок та текстових файлів (`.txt`) з довільним вмістом.
- **Редагування:** відкриття та модифікація вмісту існуючих текстових файлів із функцією збереження.
- **Деталізація:** перегляд метаданих об'єкта (назва, тип, розмір у зрозумілому форматі, дата останньої зміни).
- **Видалення:** можливість видалення файлів та папок із підтвердженням операції через системний Alert.
- **Статистика:** моніторинг використання пам'яті пристрою на головному екрані (загальний обсяг, вільно, зайнято у відсотках).

## Технічний стек
- **React Native / Expo**
- **expo-file-system:** основна бібліотека для доступу до файлової системи.
- **React Hooks:** для управління станом навігації та даними файлової системи.

Висновки
Бібліотека expo-file-system надає зручний API для роботи з локальною пам'яттю, що дозволяє реалізовувати повноцінну навігацію за принципом "дерева папок".
Використання FileSystem.getInfoAsync дає можливість отримувати метадані файлів у реальному часі, що є критично важливим для перегляду деталей об'єктів.
Передача шляхів (uri) між компонентами дозволяє легко організувати вкладену навігацію без необхідності використання складних сторонніх навігаторів для базових задач.
Візуалізація статистики пам'яті через ProgressBar на базі обчислених даних (total - free) підвищує інформативність інтерфейсу для кінцевого користувача.
